# Ponchi Release Checklist

## Build
- [ ] Проект открывается через `Ponchi.xcworkspace`
- [ ] `Debug` собирается без ошибок
- [ ] `Release` собирается без ошибок
- [ ] Финальный `Bundle Identifier` задан
- [ ] `Deployment Target` согласован
- [ ] Политика ориентаций зафиксирована

## Config
- [ ] `API base URL` вынесен из Swift-кода
- [ ] `Menu URL` вынесен из Swift-кода
- [ ] `Yandex Maps API key` вынесен из Swift-кода
- [ ] `Debug` и `Release` разделены по конфигу
- [ ] В репозитории нет случайных секретов

## Auth
- [ ] `Login` работает
- [ ] `Signup` работает
- [ ] `SMS verify` работает
- [ ] Сессия восстанавливается после перезапуска
- [ ] `Logout` работает
- [ ] `Reset password` работает
- [ ] `Delete account` доступен внутри приложения

## Orders
- [ ] Заказ создается через backend
- [ ] История заказов загружается с backend
- [ ] Статусы заказов приходят с backend
- [ ] Корзина очищается только после успешного создания заказа
- [ ] Ошибки заказа показываются пользователю

## Privacy
- [ ] `Privacy Policy` подготовлена
- [ ] `Terms`/условия подготовлены
- [ ] `App Privacy` заполнен в App Store Connect
- [ ] `Privacy manifest` добавлен при необходимости
- [ ] Данные пользователя описаны честно

## UI
- [ ] Профиль дополирован
- [ ] Экран заказов дополирован
- [ ] Есть пустые состояния
- [ ] Есть ошибочные состояния
- [ ] Основные сценарии проверены на маленьком экране
- [ ] Основные сценарии проверены на большом экране

## Assets
- [ ] `App Icon` финальный
- [ ] `Launch screen` финальный
- [ ] Все шрифты и изображения имеют понятную лицензию
- [ ] Нет ресурсов с риском для коммерческого использования

## Testing
- [ ] Пройден ручной `smoke test`
- [ ] Есть базовые unit-тесты
- [ ] Проверен сценарий без интернета
- [ ] Проверен сценарий после перезапуска приложения
- [ ] Проверен сценарий новой установки

## App Store
- [ ] Подготовлены `screenshots`
- [ ] Подготовлено описание приложения
- [ ] Заполнен `Support URL`
- [ ] Заполнен `Privacy Policy URL`
- [ ] Пройден `export compliance`
- [ ] Подготовлен `TestFlight build`
- [ ] Подготовлены заметки для `App Review`

## Final Smoke Test
- [ ] `Launch -> menu -> detail -> cart` работает
- [ ] `Login/signup` работает на чистой установке
- [ ] `Order flow` проходит до конца
- [ ] `Profile` открывается и редактируется
- [ ] `Logout` работает корректно
