# Ponchi

Ponchi — iOS‑приложение для кофейни. Проект в активной разработке и постепенно готовится к релизу.

## Текущее состояние
- SwiftUI + MVVM.
- Меню грузится из сети (JSON) с офлайн‑фоллбеком на локальный JSON.
- Экран меню с категориями, поиском, деталями товара, размерами и топпингами.
- Корзина: добавление, изменение количества, удаление, расчет суммы.
- Заказы: локальное создание заказа из корзины, список активных/завершенных заказов.
- Профиль: локальные данные пользователя, бонусы, формы входа/регистрации (пока без реального бэка).
- Карта точки через YandexMapView (если доступно в сборке).

## Архитектура и данные
- Архитектура: MVVM.
- Меню сейчас берется из удаленного JSON и дублируется в локальном JSON (фоллбек).
- Источник удаленного меню настраивается в `Ponchi/PonchiApp.swift`.

## Бэкенд (в работе)
- Используется Yandex Cloud Managed PostgreSQL.
- План: serverless API для auth по телефону (SMS), пользователей и заказов.
- После релиза планируется переход на Vapor.
- Меню позже будет перенесено в БД, чтобы сделать админку для владельца кофейни.
